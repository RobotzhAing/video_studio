# VideoFusion Studio 使用教程

## 1. 下载安装包

打开项目的 [GitHub Releases](https://github.com/willzhang35929924-ui/video_studio/releases) 页面，找到所需版本下的 **Assets**。从下表选择发布包，文件名里的版本号以发布页显示为准：

| 电脑 | 文件 | 打开软件 |
| --- | --- | --- |
| Apple 芯片 Mac | `VideoFusion-Studio-<版本>-mac-arm64.zip` | 用访达解压，再双击 `VideoFusion Studio.app` |
| Intel 芯片 Mac | `VideoFusion-Studio-<版本>-mac-x64.zip` | 用访达解压，再双击 `VideoFusion Studio.app` |
| Windows x64 | `VideoFusion-Studio-<版本>-win-x64.exe` | 双击 EXE 即可打开，无需安装向导 |

请从发布时间对应的发布页下载。GitHub 自动附带的 **Source code** 仅供开发构建。如果某个平台的文件未列出，请等待对应包上传。发布包自带后端和 FFmpeg；正常使用时不需要安装 Python 或 Node.js。系统若拦截未签名或未公证的应用，请核对来源和文件名，保持系统安全保护开启。

## 2. 配置 AI 接口

点击右上角「AI 设置」。混剪至少需要能看图的剪辑规划模型和可用的配音模型。如果参考视频带音轨，还要配置支持声音理解的模型。

| 设置 | 填写内容 | 千问模型示例 |
| --- | --- | --- |
| API Base URL | 服务商给你的兼容接口地址，通常以 `/v1` 或 `/compatible-mode/v1` 结尾 | 使用有模型权限的百炼工作空间或千问服务地址 |
| API Key | 服务商提供的密钥 | 填你的密钥 |
| 剪辑规划模型 | 有视觉能力的模型名称 | `qwen3.8-max` |
| 音频理解模型 | 能分析参考语音和配乐的模型名称 | `qwen3.5-omni-plus` |
| 配音模型 | 能生成旁白的模型名称 | `qwen-audio-3.1-tts-flash` |
| 配音音色 | 可留空，或填写模型支持的音色 | 留空自动选择 |

同样支持兼容的 OpenAI 接口。若音频理解或配音使用另一服务，展开「音频服务单独配置（可选）」，分别填写地址和密钥。接口域名、协议或端口和主服务不同时，该接口的密钥不可留空。

点击「保存设置」后，桌面版使用系统加密保存配置，重启会恢复；更换电脑时需重新配置。API 密钥不随发布包提供，不要把密钥写进仓库或发到公开讨论区。用于剪辑的画面、参考音频采样和旁白脚本会发送给对应的已配置服务；成片渲染和配乐生成在本地执行。

## 3. 建立混剪任务

1. 到「素材」点击「导入素材」，可一次选择多项。单个文件不得超过 2 GB。
2. 在「AI 混剪任务文件夹」点「新建文件夹」，填写任务名称和要求，勾选参加混剪的视频或图片。每个任务最多 100 项。
3. 如需模仿某段视频的节奏、音频或画幅，先导入该视频，再在「参考视频」下拉框选它。参考视频用于分析，不会直接进入成片，也不能同时勾为该任务的混剪素材。
4. 点击「保存文件夹」。要为多条成片分别设置素材或要求，可以建立多个任务文件夹。

可直接复制下面的示例，再按素材修改：

```text
剪成 15 秒旅行短片。开头用最精彩的镜头，结尾留一句简短总结。
成片画幅: 9:16
配音语言: en-US
字幕语言: fr-FR
配乐风格: jazz
```

文字明确指定的画幅优先；没写画幅时，先跟随参考视频，再跟随素材。写 `成片画幅: 9:16` 可得到 1080×1920 竖屏成片，`16:9` 则为 1920×1080 横屏成片。字幕默认跟随配音语言；混剪字幕不使用汉字，日语可用假名，中文可用拼音。

## 4. 批量生成、播放和下载

切换到「AI 助手」，点击「启动批量 AI 混剪」。程序会按任务文件夹生成剪辑方案、配音、配乐和字幕，再渲染成片。某个任务失败时，其他任务仍可继续。

- 成片卡片出现后，点击「播放」可在右侧播放器预览。
- 点击「下载」可把 MP4 保存到本机。任务名用于生成文件名，重名时自动编号。
- 如需继续修改，在成片下方填写意见并点「修改混剪」。例如：`开头更快，换成爵士配乐，保留 9:16 画幅`。修改会生成新成片，原版仍可查看。若旧成片没有保存修改方案，请从原任务重新生成；如果已删除修改所需的原素材，则不能修改该成片。

## 5. 翻页、选择和清理

素材、任务文件夹及成片列表每页显示 10 条。素材和成片均可逐项勾选，也可点击「全选本页」。全选只作用于当前页，翻页会清空上一页的勾选状态。

- 「永久删除所选素材」会移除程序管理的素材副本及任务引用；已经生成的成片不会因此删除。
- 「永久删除所选成片」会移除成片记录和对应的本地渲染文件。
- 两种删除都不会进入废纸篓。导入前的原始文件、下载到其他位置的成片副本不受影响。

## 常见问题

- **软件打不开**：确认下载的是运行包，Mac 已完整解压，且所选包与芯片架构一致。若有安全提示或启动报错，保存提示截图，在仓库提交问题时附上系统、芯片和版本号，遮盖 API 密钥。
- **混剪提示接口错误**：先核对服务地址、密钥、模型名称和模型权限。参考视频带音轨时，需要支持音频理解的模型；只有文字或语音转写能力的模型不能分析配乐。
- **Windows 下载后不见安装程序**：标记为 `win-x64.exe` 的便携版是启动程序本身；不要双击源码压缩包。
